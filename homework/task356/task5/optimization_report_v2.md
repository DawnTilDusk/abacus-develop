# Task 5 第二轮优化：v1 线格式 + 并行解压 + 自动回退

Date: 2026-06-06

## 做了什么

1. **v1 线格式** ("ZCM2")：新增 `fmt_type` 字节精确区分 serial/OMP，消除 v0 中通过 nthreads 字段判断的歧义
2. **自动回退**：压缩膨胀时（如随机数据）自动存原始数据，`flags & 0x01` 标记
3. **OpenMP 并行解压**：补齐 v0 和 v1 的解压侧并行（第一轮只并行化了压缩）
4. **通用解压** `decompress_charge_data_any()`：单一入口，自动检测 v0/v1、serial/OMP 四种格式
5. **完全向后兼容**：v0 ZCMP magic 不变，旧文件仍可读取

## 格式对比

| | 第一轮 (v0) | 第二轮 (v1) |
|---|:---------:|:---------:|
| Magic | ZCMP | ZCM2 |
| Header 大小 | 12B / 16B | 14B / 16B |
| 格式识别 | nthreads 推断 (有歧义) | fmt_type 字节 (精确) |
| 压缩失败处理 | 报错退出 | 自动回退存原始数据 |
| 解压 | 串行 | **OpenMP 并行** |
